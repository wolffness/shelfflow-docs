A **curadoria manual** é o modo mais poderoso do ShelfFlow. Em vez de depender de algoritmos ou categorias, você escolhe exatamente quais produtos aparecem e em qual ordem.

## Por que curadoria manual?

Todo lojista sabe que nem todos os produtos têm a mesma importância. A **curva ABC** do varejo mostra que:

- **~20% dos produtos** geram **~80% da receita**
- Esses produtos precisam de **visibilidade máxima** na homepage
- A ordem importa: o primeiro produto do slider recebe mais cliques

Com a curadoria manual, você coloca seus produtos estrela na frente, na posição certa.

## Como usar

1. Ao criar ou editar uma prateleira, selecione **Curadoria manual**
2. Busque os produtos pelo nome ou SKU
3. Clique nos produtos para adiciona-los
4. **Arraste** os produtos para reordenar — o primeiro da lista é o primeiro do slider
5. Salve a prateleira

<Aside type="tip">
  A ordem dos produtos é **garantida**. O ShelfFlow salva um snapshot dos produtos no banco de dados para manter a sequência exata que você definiu, independente da API da plataforma conectada.
</Aside>

## Estratégias de curadoria

### Curva ABC
Coloque os 20% mais vendidos no início do slider. Eles já têm demanda comprovada — dar visibilidade só aumenta as vendas.

### Cross-sell
Monte prateleiras temáticas que combinam produtos complementares. Exemplo: "Look Completo" com blusa + calca + acessorio.

### Lançamentos
Use uma prateleira dedicada para novidades. Atualize semanalmente para manter a homepage fresca.

### Queima de estoque
Destaque produtos com estoque alto que precisam girar. Combine com desconto para maximizar o efeito.

## Limites

- Máximo de **30 produtos** por prateleira em curadoria manual
- Não há limite de prateleiras por loja
- Cada prateleira pode ter seu próprio conjunto de produtos curados
