**Upsell** permite sugerir produtos no carrinho com base no contexto da compra. Use campanhas para recomendar complementos, kits ou produtos relacionados antes do cliente finalizar o pedido.

## Antes de começar

- Upsell fica no plano Shelf+ durante o pré-lançamento.
- A loja precisa ter produtos importados no ShelfFlow.
- A campanha precisa de gatilho, oferta e preview revisado antes de publicar.
- Desconto real depende de capability de desconto confirmada para a loja.

## Quando usar

- Sugerir complemento para produto ou categoria no carrinho.
- Aumentar ticket médio com produtos de menor fricção.
- Promover kits ou combinações que já fazem sentido comercial.
- Destacar produtos com boa margem ou estoque forte.

## Criar uma campanha

<Steps>
1. Acesse **Upsell** no dashboard.
2. Clique para criar uma nova campanha.
3. Escolha o gatilho: produto, categoria, valor do carrinho ou regra disponível.
4. Defina quais produtos serão sugeridos.
5. Configure benefício, copy e aparência.
6. Revise a prévia no carrinho.
7. Confira as verificações finais.
8. Clique em **Publicar campanha**.
</Steps>

## Como saber se funcionou

- A campanha aparece na lista de Upsell.
- O status indica que ela foi publicada ou ficou como rascunho com pendência clara.
- A prévia usa produtos reais escolhidos na campanha.
- Quando o carrinho atende ao gatilho, a oferta fica elegível para aparecer.

<Aside type="caution">
  Não comunique desconto como garantido se a loja ainda não tem desconto real validado no checkout. Nesses casos, trate a oferta como recomendação de produto.
</Aside>

## Ajustes comuns

- Use gatilhos por categoria quando muitos produtos devem ativar a mesma oferta.
- Use produtos específicos quando a campanha depende de um item principal.
- Revise o preview sempre que trocar os produtos sugeridos.
- Pausar uma campanha é melhor do que apagar quando você quer preservar histórico.

## Problemas comuns

| Sintoma | Causa provável | Como resolver |
|---|---|---|
| Campanha não aparece no carrinho | Gatilho não atendido ou campanha em rascunho | Revise regra, status e preview |
| Preview mostra produto inesperado | Produto sugerido antigo ou seleção incompleta | Volte ao passo de produtos e salve novamente |
| Desconto não aplica | Capability de desconto ausente ou regra não confirmada | Verifique o estado de desconto antes de prometer economia |
| Publicação volta para estado vazio | Campanha não foi persistida ou houve erro de refresh | Recarregue a tela e confira a lista antes de recriar |
