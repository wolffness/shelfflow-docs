Esta página cobre o que é específico da integração com **Nuvemshop**. Para aprender os conceitos gerais do ShelfFlow, comece pela [visão geral](/getting-started/) e pelo [Quick Start](/getting-started/quick-start/).

## Antes de começar

- Tenha acesso de administrador a loja.
- Confirme que você pode autorizar aplicativos e permissões da plataforma.
- Se usar Google Tag Manager, tenha acesso ao container atual.
- Se a loja usa tema customizado, reserve tempo para validar a vitrine publicada.

## Instalar a coleta

<Steps>
1. **Conecte a loja**

   Acesse o dashboard do ShelfFlow e confirme que a loja Nuvemshop correta está ativa.

2. **Escolha o caminho de instalação**

   Use o Google Tag Manager quando a loja já opera com GTM. Se o setup exigir scripts diretos, siga as instruções mostradas no app para storefront e checkout.

3. **Faça backup antes de importar**

   Antes de importar qualquer container, exporte o container atual do GTM. Isso permite restaurar a configuração se algo sair diferente do esperado.

4. **Publique a coleta**

   Importe o container ou publique os scripts conforme o caminho escolhido.

5. **Abra a loja publicada**

   Acesse a loja em uma aba anônima para gerar os primeiros eventos de validação.
</Steps>

## Validar que funcionou

- O status de tracking no ShelfFlow não deve mostrar erro crítico.
- Uma vitrine publicada deve aparecer no storefront no local esperado.
- Os primeiros eventos podem levar algum tempo para aparecer; `em validação` não significa erro por si só.
- O Analytics deve começar a mostrar impressões ou cliques quando houver tráfego real.

<Aside type="tip">
  O guia antigo de setup detalha o fluxo Nuvemshop + GTM passo a passo: [Configurar Nuvemshop + GTM](/guides/nuvemshop-setup/).
</Aside>

## Problemas comuns

| Sintoma | Causa provável | Como resolver |
|---|---|---|
| A vitrine não aparece | Coleta não publicada, posição indisponível ou tema customizado | Revise a instalação, publique novamente e teste outra posição |
| O tracking fica em validação | Ainda não houve evento real suficiente | Abra a loja publicada, navegue por produtos e aguarde a coleta |
| O layout fica diferente do preview | Tema customizado ou CSS da loja | Teste outra posição e revise compatibilidade de tema |
| O GTM mudou algo fora do ShelfFlow | Importação sem backup ou conflito de tags | Restaure o backup do container e importe novamente com merge |
