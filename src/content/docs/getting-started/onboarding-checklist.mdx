Use este checklist para acompanhar a ativacao da loja.

## 1. Conta e loja

- Voce consegue entrar no dashboard.
- A loja correta aparece como ativa.
- As preferencias iniciais foram preenchidas.
- O segmento da loja e o perfil visual fazem sentido para seus produtos.

## 2. Coleta instalada

- O GTM foi salvo em backup antes de importar o container do ShelfFlow.
- O container ou script foi publicado.
- O status de tracking no ShelfFlow nao mostra erro critico.
- A homepage foi aberta depois da instalacao para gerar os primeiros eventos.

<Aside type="tip">
  Se o status aparecer como "em validacao", aguarde eventos reais da loja. Isso e diferente de erro critico.
</Aside>

## 3. Primeira vitrine publicada

- Existe uma vitrine ativa.
- A vitrine tem titulo claro para o cliente.
- Os produtos escolhidos estao disponiveis.
- O preview foi conferido.
- A vitrine aparece na homepage publicada.

## 4. Primeiros sinais

- O Analytics mostra impressoes ou cliques.
- A leitura por vitrine esta disponivel.
- A loja tem sinais suficientes antes de tirar conclusoes comerciais.
- Se houver pedidos, a atribuicao de vendas comeca a aparecer conforme a coleta amadurece.

## 5. Inteligencia

- A aba **Hoje** foi revisada.
- A aba **O que vende** foi aberta.
- A leitura usa categorias, vitrines e produtos reais da loja.
- Sugestoes sao executadas apenas quando fazem sentido para o contexto comercial.

## Shelf+

Clientes Shelf+ podem usar este checklist como pauta da chamada de onboarding personalizada:

1. validar instalacao;
2. escolher a primeira vitrine;
3. conferir a coleta;
4. revisar primeiros sinais;
5. priorizar proximas vitrines e oportunidades.
