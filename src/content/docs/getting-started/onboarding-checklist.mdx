Use este checklist para acompanhar a ativação da loja.

## 1. Conta e loja

- Você consegue entrar no dashboard.
- A loja correta aparece como ativa.
- As preferências iniciais foram preenchidas.
- O segmento da loja e o perfil visual fazem sentido para seus produtos.

## 2. Coleta instalada

- O guia da plataforma conectada foi seguido.
- O gerenciador de tags, tema ou script foi salvo em backup antes de qualquer importação, quando aplicável.
- O container, script ou app de coleta foi publicado.
- O status de tracking no ShelfFlow não mostra erro crítico.
- A homepage foi aberta depois da instalação para gerar os primeiros eventos.

<Aside type="tip">
  Se o status aparecer como "em validação", aguarde eventos reais da loja. Isso é diferente de erro crítico.
</Aside>

## 3. Primeira vitrine publicada

- Existe uma vitrine ativa.
- A vitrine tem título claro para o cliente.
- Os produtos escolhidos estão disponíveis.
- O preview foi conferido.
- A vitrine aparece na homepage publicada.

## 4. Primeiros sinais

- O Analytics mostra impressões ou cliques.
- A leitura por vitrine está disponível.
- A loja tem sinais suficientes antes de tirar conclusões comerciais.
- Se houver pedidos, a atribuição de vendas começa a aparecer conforme a coleta amadurece.

## 5. Inteligência

- A aba **Hoje** foi revisada.
- A aba **O que vende** foi aberta.
- A leitura usa categorias, vitrines e produtos reais da loja.
- Sugestões são executadas apenas quando fazem sentido para o contexto comercial.

## Shelf+

Clientes Shelf+ podem usar este checklist como pauta da chamada de onboarding personalizada:

1. validar instalação;
2. escolher a primeira vitrine;
3. conferir a coleta;
4. revisar primeiros sinais;
5. priorizar próximas vitrines e oportunidades.
