## Como o ShelfFlow detecta o tema

O ShelfFlow não precisa saber qual tema você usa. Em vez disso, ele procura **elementos HTML semânticos** que são comuns entre os temas clássicos da Nuvemshop:

- `[data-store="home-slider"]` — banner principal
- `section[data-store="home-products-featured"]` — produtos em destaque
- `[data-store="home-banner-promotional"]` — banners promocionais
- `footer` — rodapé

Se o seu tema usa classes CSS diferentes (por exemplo, um tema customizado), você pode informar um **seletor CSS customizado** na configuração da prateleira.

## Temas customizados

Se você usa um tema customizado ou comprado de terceiros:

1. O posicionamento automático **pode funcionar** se o tema seguir a estrutura padrão da Nuvemshop
2. Se não funcionar, use um **seletor CSS customizado** na configuração da prateleira
3. Para encontrar o seletor correto, use o **Inspecionar Elemento** do navegador (F12) e procure o elemento após o qual você quer inserir a prateleira

<Aside type="tip">
  Copie o seletor CSS do elemento desejado (ex: `.meu-banner-principal`) e cole no campo "Seletor CSS customizado" da prateleira. O ShelfFlow vai usar esse seletor como referência.
</Aside>
