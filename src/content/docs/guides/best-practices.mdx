Ter prateleiras na homepage é só o começo. O que realmente faz diferença é **o que você coloca nelas** e **como você organiza**. Aqui estão as melhores práticas que aprendemos com lojistas reais.

## 1. Aplique a curva ABC

A regra de Pareto se aplica ao e-commerce: cerca de 20% dos seus produtos geram 80% da receita. Esses são seus **produtos A** — eles devem ter máxima visibilidade.

**Como aplicar:**
- Identifique seus 10-20 produtos mais vendidos
- Crie uma prateleira "Mais Vendidos" com curadoria manual
- Coloque-a na posição mais visível (após o banner)
- Coloque os mais vendidos **primeiro** no slider (posição 1-3)

## 2. Use títulos que vendem

O título da prateleira é a primeira coisa que o visitante lê. Bons títulos criam contexto e desejo.

| Genérico | Estratégico |
|----------|-------------|
| Produtos | Mais Vendidos |
| Novidades | Acabou de Chegar |
| Categorias | Para Presentear |
| Destaques | Você Vai Amar |

## 3. Crie prateleiras temáticas

Em vez de uma prateleira genérica com produtos aleatórios, crie vitrines com **narrativa**:

- **"Look Completo"** — blusa + calca + acessorio
- **"Presentes até R$ 50"** — faixa de preço acessível
- **"Tendência da Estação"** — produtos sazonais
- **"Ultimas Unidades"** — urgencia para produtos com estoque baixo

## 4. Atualize regularmente

Uma homepage estática passa a impressão de loja abandonada. Atualize suas prateleiras pelo menos **1x por semana**:

- Troque produtos que não estão vendendo
- Adicione lançamentos
- Destaque promoções vigentes
- Remova produtos sem estoque

<Aside type="tip">
  Use o **dashboard de analytics** para identificar quais produtos têm baixo CTR e substitua-os por novos candidatos.
</Aside>

## 5. Não exagere no número de prateleiras

Menos é mais. Uma homepage com 5+ prateleiras fica cansativa. Recomendamos:

- **1-2 prateleiras** para lojas pequenas (< 50 produtos)
- **2-3 prateleiras** para lojas medias (50-200 produtos)
- **3-4 prateleiras** para lojas grandes (200+ produtos)

## 6. Posicione estrategicamente

A ordem das seções na homepage importa:

1. **Banner** (já existe no tema)
2. **Mais Vendidos** — prateleira ShelfFlow, posição "após o banner"
3. **Destaques do tema** (já existe)
4. **Lançamentos** — prateleira ShelfFlow, posição "após os destaques"
5. **Banners promocionais** (já existe)
6. **Footer**

<Aside>
  Use o analytics para comparar o CTR entre posições. Se uma prateleira "após o banner" tem CTR muito superior, considere mover as outras para posições mais altas também.
</Aside>
